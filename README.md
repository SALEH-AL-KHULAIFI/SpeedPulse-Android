# SpeedPulse — مؤشر سرعة الإنترنت

تطبيق أندرويد خفيف يعرض سرعة التنزيل والرفع بشكل واضح، مع خيار إبقاء فقاعة صغيرة بجوار البطارية فوق التطبيقات الأخرى.

## تشغيل المعاينة

```bash
pnpm install
pnpm --filter @workspace/internet-speed-indicator run dev
```

يمكن معاينة الواجهة في Expo Go. في المعاينة يظهر القياس التجريبي المرئي؛ أما مؤشر شريط الحالة الفعلي فيعمل بعد إنشاء نسخة Android من المشروع ومنح صلاحية **الظهور فوق التطبيقات**.

## إنشاء نسخة Android من GitHub

```bash
pnpm install
npx expo prebuild --platform android
cd android
./gradlew assembleRelease
```

الـ config plugin الموجود في `plugins/withSpeedOverlay.js` يضيف:

- إذن الظهور فوق التطبيقات.
- خدمة foreground خفيفة تعمل بـ `TrafficStats`.
- فقاعة سرعة واضحة أعلى الشاشة قرب منطقة البطارية.
- إشعار دائم منخفض الأهمية حتى يسمح Android باستمرار الخدمة في الخلفية.

لا يحتاج التطبيق إلى خادم أو قاعدة بيانات؛ الإعدادات محلية، لذلك يبقى المشروع صغيراً ومناسباً للرفع إلى GitHub. قبل النشر في Play Store، يجب إضافة أيقونة نهائية وبيانات المطور وسياسة الخصوصية المطلوبة من Google Play.

## حدود Android المهمة

لا يسمح Android بتعديل أيقونة البطارية نفسها لتطبيق عادي. الحل المدعوم هو فقاعة overlay بجوارها مع إذن المستخدم، ويظهر التطبيق هذا الإذن من زر التمكين فقط.
